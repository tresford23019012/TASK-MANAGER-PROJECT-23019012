# Project Description
Tresify is a modern personal productivity web application built with React.
It helps students manage their daily tasks, schedule their course modules,
and plan their weekly gym sessions — all in one place.

---

# Features
- Task Manager — Add, view, edit, delete and complete tasks
- Search & Filter — Search tasks by name and filter by category
- Module Timetable — Schedule courses Monday to Friday, 8AM to 6PM
- Gym Planner — Plan weekly workout sessions with editable cards
- Modern UI — Dark mode with periwinkle color theme
- Responsive — Works on desktop, tablet and mobile

---

# Technologies Used
- React (Vite)
- React Router DOM
- CSS-in-JS (inline styles)
- JavaScript (ES6+)
- Node.js & npm
